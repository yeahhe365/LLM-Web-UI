## Overview

A lightweight LLM web chat UI with Markdown/LaTeX rendering, streaming output, multi-session management, multiple API configs, and local data storage.

## Features

- Streaming chat UI.
- Markdown and LaTeX rendering.
- Multi-session and multi-API configuration.
- Local data storage.

## Quick Start

- Enter the `LLM-Web-UI` directory.
- Serve the project with a local static server, or follow the existing README deployment notes.
- Configure the API service in the UI.

## Configuration

- Configure API endpoint, key, and model parameters in the web UI.

## Tech Stack

- JavaScript
- Markdown/LaTeX rendering
- local storage
